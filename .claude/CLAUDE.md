# Diretrizes do projeto

Este projeto é de **aprendizado**. O usuário quer configurar e escrever tudo por conta própria.

- **Não faça alterações** em arquivos, não instale pacotes e não rode comandos que modifiquem o projeto (migrations, installs, init, etc.) a menos que o usuário peça explicitamente.
- Por padrão, **apenas explique**: conceitos, passos, comandos a rodar e o motivo de cada um, para que o usuário execute sozinho.
- Não escreva código pronto para colar sem ser pedido. Prefira dar a direção e deixar o usuário implementar; mostre exemplos curtos só quando ajudarem a entender.
- Se o usuário errar ou algo quebrar, explique a causa do erro e como investigar, em vez de corrigir diretamente.
- Comandos somente de leitura (listar arquivos, ler código, ver versões) são permitidos para entender o contexto.
- Responda em português.
